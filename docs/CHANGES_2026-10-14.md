# 2026-10-14 开源整理记录

仅修改独立副本，原始移交文件保持不变。

1. 修复默认 admin 角色无法访问后台管理接口的问题，保留 super / manager 兼容。
2. 新密码采用随机盐 scrypt；兼容历史 SHA-256 密码，成功登录后升级存储。新注册密码要求 12–128 位。

7. 小程序请求、埋点和全局地址统一使用 config.js；公开配置开启域名检查；删除本机私有配置。
8. 自动生成本机随机 JWT 与 MySQL 密码；Docker 密码读取 .env，数据库只绑定本机，添加健康检查与持久化卷；数据库初始化限制固定库名。
