# 三端联动交互演示

更新时间：2026-10-15。打开根目录 index.html，在“下一次打卡，家属就看见了”区域操作。桌面并排展示三端；窄屏使用端切换按钮。所有状态只存在当前页面内存中，刷新或重置后清空，无后台连接、真实支付、图片上传或消息发送。

## 体验路线

1. 用户端选择服务、科室和时段，勾选演示授权，提交虚构预约。
2. 机构端核对需求与风险关注项，勾选评估确认，受理并发送服务方案。
3. 用户端确认服务方案与模拟服务约定，模拟支付；陪诊员端出现任务。
4. 陪诊员接单，逐项确认服务前联系人、材料、行动需求、医院安排与会合信息。
5. 到院后核对对象与授权，依次体验11个项目节点；检查、送检、缴费、取药和报告可记录本次不涉及。
6. 每次打卡都在家属进度、家属动态和机构全链路记录同步呈现。可填写虚构说明并附虚拟凭证标记；输入仅作为文本展示。
7. 选择“模拟突发情况”，演示暂停常规节点，家属和管理端出现提醒；机构勾选模拟现场反馈后恢复。没有实际联系医护或实施任何医疗处置。
8. “追加更正示例”新增一条说明，保留原记录。
9. 离院前确认材料、后续领取方式与医嘱提醒，提交交接清单；用户端模拟服务对象或其法定监护人确认，完成服务。

11个节点沿用现有项目枚举，不是国标规定的固定顺序或每位患者必经路径。三端即时同步、交互门禁、异常暂停与恢复、交接确认等为本页面设计，不代表现有后端已经具备这些完整能力，不构成认证或符合性结论。

当前后端已有节点追加、权限查看和更正说明接口；本页没有调用这些接口。实际多设备实时同步、推送、应急处置、合同与授权、交接签收和私有文件存储仍需相应工程与业务验证。远程家属可见不等于自动取得法定监护人或医疗文书签署权。
